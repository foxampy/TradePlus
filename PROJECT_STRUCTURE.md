# Trade+Plus - Структура проекта

## Общее описание
Trade+Plus - это инновационное приложение для трейдеров всех уровней с уникальным дизайном в стиле киберпанк.

## Дизайн
- Цветовая схема:
  - Основной фон: темно-серый матовый
  - Элементы интерфейса: черное стекло
  - Акценты: неоновые рамки (розовый и мятный)
  - Анимация: мягкое статичное переливающееся свечение

## Основные компоненты

### 1. Навигация
- Менюбар (свайп слева)
- Фиксированная кнопка меню в верхнем колонтитуле
- Структура меню:
  1. PLUS
  2. Аккаунт
     - Кошельки
     - Сообщения
     - Контакты
     - Группы
  3. Торговля
     - Торговать
     - P2P
     - Стейкинг
     - Биржи
     - Вывод
  4. Инвестиции
     - ICO
     - Аирдропы
     - Краундфайдинг
  5. Дополнительно
     - Обучение
     - Настройки
     - В разработке

### 2. Функциональные блоки

#### Аутентификация
- Регистрация через email/пароль
- Авторизация через Telegram
- Подтверждение email
- Восстановление пароля

#### Личный кабинет
- Профиль пользователя
- Настройки безопасности
- История действий
- Статистика

#### Обучение
- Интерактивные туториалы
- Пошаговые инструкции
- Геймификация процесса обучения
- Система достижений

#### Токеномика
- Начисление токенов за:
  - Изучение бета-версии
  - Регистрацию
  - Приглашение друзей
  - Прохождение обучения
- Система рефералов
- Внутренний баланс

### 3. Технические требования
- Frontend: React/Next.js
- Backend: Node.js/Python
- База данных: PostgreSQL
- Аутентификация: JWT
- WebSocket для реального времени
- API интеграции с биржами
